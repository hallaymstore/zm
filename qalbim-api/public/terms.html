Foydalanish shartlari

Amal qilish sanasi: 27-oktabr 2026-yil. Ro‘yxatdan o‘tib, xizmatdan foydalanish orqali ushbu shartlarga rozilik bildirasiz.

1. Hisob

18 yoshga to‘lgan shaxs o‘z telefon raqami va parol bilan hisob ochadi. Telefon raqami hozircha SMS orqali tasdiqlanmaydi. Ro‘yxatdan o‘tgan shaxs kirish ma’lumotlarini himoya qilishga mas’uldir. Begona raqamdan ruxsatsiz foydalanish taqiqlanadi.

2. Maktub va rasmlar

Faqat o‘zingizga tegishli yoki ishlatishga ruxsat berilgan matn va rasmlarni yuboring. Boshqalarning roziligisiz intim suratlari, tahdid, shantaj, firibgarlik, haqorat, noqonuniy yoki mualliflik huquqini buzuvchi materiallar taqiqlanadi. Havola orqali ulashilgan maktubni har kim ko‘rishi mumkin.

3. Juftlik va chat

Juftlik ikki hisobning o‘zaro taklif va qabul qilish harakati bilan bog‘lanadi. Bir foydalanuvchi bir vaqtning o‘zida bitta juftlikda bo‘lishi mumkin. Ulanishni uzish chat tarixining o‘chishiga olib keladi. O‘chib ketuvchi xabarlarni ekran tasviri, nusxa yoki boshqa qurilmada saqlashni texnik jihatdan to‘liq cheklab bo‘lmaydi.

4. Pro va to‘lov

Pro ruxsati hozircha avtomatik to‘lov orqali emas, administrator bilan Telegram orqali kelishilgach qo‘lda faollashtiriladi. 3 va 7 kunlik muddatlar mavjud. To‘lov summasi, usuli va qaytarish shartlari kelishuvdan oldin aniq ko‘rsatilishi lozim. Shartlar ochiq belgilanmaguncha to‘lovni tasdiqlangan deb hisoblamang. Tarif muddati tugashi bilan Pro funksiyalar bloklanadi.

Telegram Mini App va avtomatik to‘lov

Telegram Mini App bilan yaratilgan hisob oddiy sayt bilan umumiy ma’lumotlar bazasidan foydalanadi. Telegram birinchi kirishda ro‘yxatdan o‘tish va rozilik talab qilinadi, keyingi kirishlarda Telegramning tasdiqlangan imzosi bilan hisob ochiladi. Hamyon API orqali Pro uchun to‘lov yaratilib, maxsus summa va karta rekviziti ko‘rsatiladi. Hamyon API to‘lovni tasdiqlab, server tekshiruvlari muvaffaqiyatli yakunlangach Pro avtomatik faollashadi. Kartaga pul o‘tkazishdan oldin summa, karta, to‘lov muddati va operator shartlarini tekshiring. To‘lovga oid nizolarni operator bilan hal eting.

Telegram Stars

Telegram Mini App ichida raqamli Pro obuna faqat Telegram Stars (XTR) orqali sotiladi. Oddiy veb-saytdagi Hamyon API kartali to‘lov tizimi Telegram Mini App ichida taklif qilinmaydi. Stars uchun narxlar alohida ko‘rsatiladi; to‘lovni faqat Telegram tasdiqlagach Pro faollashadi. To‘lov masalalari uchun botning /paysupport buyrug‘idan foydalanish mumkin.

5. Moderator nazorati

Operator hisoblarni bloklashi, noqonuniy/shikoyat qilingan maktublarni o‘chirishi va qoidabuzarlik bo‘yicha zarur choralarni ko‘rishi mumkin. Oddiy admin interfeysi foydalanuvchilar chat matnini umumiy ko‘rish uchun ochmaydi, ammo server administratorlari ma’lumotlarga texnik kirish imkoniyatiga ega.

6. Kafolatlar

Xizmat beta bosqichida bo‘lib, vaqtincha uzilishlar yuz berishi mumkin. Xabarlarning o‘chishi apparat va ma’lumotlar bazasi ish jadvaliga bog‘liq. Platformadan foydalanib, uchinchi shaxslar maxfiyligini hurmat qilishga rozilik berasiz.

7. Shartlarni o‘zgartirish va bog‘lanish

Muhim o‘zgarishlar foydalanuvchilarga xabar qilinishi va zarur bo‘lsa qayta rozilik olinishi lozim. Savollar va hisobni o‘chirish bo‘yicha ilovadagi admin Telegram kanaliga murojaat qiling.

Ommaviy tijorat faoliyatidan oldin haqiqiy xizmat operatori rekvizitlari, narxlar, to‘lov siyosati va O‘zbekistonning shaxsga doir ma’lumotlar talablari bo‘yicha huquqiy tekshiruv talab etiladi.
